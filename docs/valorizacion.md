# Valorización de servicios

Usar Chuchunco es **gratuito**. Estos son valores de referencia que el C3P usa en las **cartas de apoyo para postulaciones a fondos**, para indicar cuánto aporta la universidad cuando un proyecto usa el clúster. No son un cobro.

## Valores (USD, 2026)

| Servicio | Valor |
|---|---|
| 1 hora de CPU (una «CPU» de Slurm, es decir, un hilo de procesador) | US$ 0,006 |
| 1 hora de GPU (NVIDIA RTX 6000 Ada o AMD Instinct MI210) | US$ 0,55 |
| Almacenamiento (3 copias en 3 servidores) | US$ 120 por TB al año |

**Cómo se calculan:** el costo de los equipos repartido en 5 años, más los costos de operación (energía, refrigeración), dividido por las horas que el clúster puede entregar en la práctica. Se revisan cada año.

## Ejemplo

Un proyecto que en un año usa 50.000 horas de CPU, 2.000 horas de GPU y 5 TB:

| | Cálculo | Valor |
|---|---|---|
| CPU | 50.000 × US$ 0,006 | US$ 300 |
| GPU | 2.000 × US$ 0,55 | US$ 1.100 |
| Almacenamiento | 5 × US$ 120 | US$ 600 |
| **Total** | | **US$ 2.000** |

## Pedir una carta

Escribe a hpc.fisica@usach.cl con:

- el proyecto: título, investigador/a responsable y período;
- una estimación de horas de CPU, horas de GPU y TB de almacenamiento.

Si el proyecto ya está usando el clúster, usamos su uso real. Los montos en pesos se calculan con el dólar observado de la fecha de la carta.
